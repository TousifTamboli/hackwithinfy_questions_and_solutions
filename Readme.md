# HackWithInfy Questions & Solutions

A community-driven collection of **HackWithInfy questions, problem statements, approaches, and solutions**.

This repository is intended to help students and developers prepare for **HackWithInfy coding rounds** by keeping useful questions and their solutions in one place.

> If you find this repository useful, consider giving it a star and sharing it with others preparing for HackWithInfy.

## Repository

**GitHub:**
https://github.com/TousifTamboli/hackwithinfy_questions_and_solutions

---

## What You'll Find Here

This repository aims to collect:

* HackWithInfy coding questions
* Previous/reported questions
* Problem statements
* Solutions and explanations
* Different approaches where useful
* Time and space complexity
* Test cases
* Optimized solutions

The goal is to make this a **growing community resource** rather than just a collection of code.

---

## Why This Repository?

HackWithInfy questions can vary across different rounds and years. Finding reliable questions and solutions scattered across different places can be difficult.

This repository brings them together so you can:

1. Practice previously encountered questions.
2. Understand different problem-solving approaches.
3. Compare brute-force and optimized solutions.
4. Learn common patterns such as DP, graphs, greedy, binary search, recursion, etc.
5. Contribute questions and solutions you encounter.

# Contributing

Contributions are highly welcome.

If you have:

* A new HackWithInfy question
* A question from a previous test
* A better or optimized solution
* A missing test case
* A useful explanation
* A correction to an existing solution

feel free to contribute.

## How to Contribute

### 1. Fork the Repository

Click the **Fork** button at the top-right of the GitHub repository.

### 2. Clone Your Fork

```bash
git clone https://github.com/<your-username>/hackwithinfy_questions_and_solutions.git
```

### 3. Create a New Branch

Avoid making changes directly on `main`.

```bash
git checkout -b add-new-question
```

### 4. Add Your Contribution

Add the question, solution, or improvement following the repository's existing structure.

For example:

```text
questions/
└── problem-name/
    ├── README.md
    └── solution.cpp
```

A problem's `README.md` should preferably contain:

```text
Problem Statement
Input
Output
Constraints
Examples
Approach
Complexity
```

### 5. Commit Your Changes

```bash
git add .
git commit -m "Add solution for <problem-name>"
```

### 6. Push Your Branch

```bash
git push origin add-new-question
```

### 7. Create a Pull Request

Open the repository on GitHub and create a **Pull Request** from your branch to `main`.

Please provide a short description explaining what you added or changed.

## Contribution Guidelines

To keep the repository organized and useful, please follow these guidelines.

### Problem Statements

When adding a question, try to include the complete problem statement.

Include, where available:

* Problem description
* Input format
* Output format
* Constraints
* Example input
* Example output

### Solutions

Prefer clean and readable code.

Whenever possible, mention:

```text
Approach
Time Complexity
Space Complexity
```

### Correctness

Please test your solution before submitting a Pull Request.

Avoid submitting untested or incomplete solutions.

### Duplicates

Before adding a new question, search the repository to make sure the same question does not already exist.

If it is a variation of an existing problem, clearly mention the difference.

## Recommended Solution Format

For consistency, a solution can follow this structure:

```cpp
#include <bits/stdc++.h>
using namespace std;

void solve() {
    // Solution
}

int main() {
    solve();
    return 0;
}
```

The accompanying explanation can follow:

```text
## Approach

Explain the main idea.

## Complexity

Time: O(...)
Space: O(...)
```
